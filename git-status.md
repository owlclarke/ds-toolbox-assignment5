# Definition: git status  

git status is a Git command that provides information about the current state of a working directory and staging area. It displays changes that have been staged, changes that need to be staged before making a commit, as well as files which are not being tracked by Git. It can also be used to verify the current branch that you are working on, and to check for merge conflicts and resolve them.  

The Git panel in Jupyter Lab allows you to see a visualization of the above information. The Current Branch displays the branch you are on. The Changes shows unstaged and staged changes, as well as untracked files (though gitignore will cease the display of these files, if desired). Different File Actions can be made to all files.
